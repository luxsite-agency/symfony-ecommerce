# Чекліст запуску магазину

«1–2 дні» — це технічний запуск (пункти 1–8). Тексти, SEO, юридичне, аналітика — окремий трек, 1–2 тижні календаря.

## Технічний запуск
1. [ ] Бриф заповнено (`docs/brief.md`), факти з джерелами.
2. [ ] Пак: `bin/store new <key> <домен>`; запис у `stores.yaml` рушія (PR), репо пака приватне в luxsite-agency, команда developers.
3. [ ] `bin/store validate <key>` — без помилок.
4. [ ] DNS технічного домену / Cloudflare; сервер (наш або клієнта: Docker, користувач deploy у групі docker, 2 vCPU/2–4 ГБ).
5. [ ] `bin/store deploy <key>` на технічний домен (noindex); адмінка відкривається.
6. [ ] Каталог: `catalog:import:feed catalog/products.csv --source=<key>`; фото; перевірити ціни й «ціна за запитом».
7. [ ] Тема: лого, кольори, шрифти (ліцензія), банер; перевірка на мобільному.
8. [ ] Оформлення: COD і/або безготівка + Нова пошта (ключ НП — на сервері / в Settings); тестове замовлення. Адмінку видано клієнту.

## Контент і запуск на бойовому домені
9. [ ] Тексти категорій і сторінок (`content/`): Gemini → редактура → deai.
10. [ ] SEO (`seo/`): семантика, мета, перелінковка.
11. [ ] Юридичне: оферта й політика з реальними реквізитами (без плейсхолдерів `[…]`), футер `legal`.
12. [ ] Зовнішня контент-панель: сайт, персона й промпти (`studio/`), 3 статті.
13. [ ] KeyCRM (якщо є), аналітика (GTM/GA4), analytics-healthcheck.
14. [ ] Бекап: `bin/store backup <key>` і пробне відновлення; `bin/store doctor <key>` зелений.
15. [ ] Бойовий домен, зняття noindex, `status: active` у реєстрі.
