# Правила агента магазину Store Template (storetemplate)

Це пак магазину на рушії Symfony ecommerce LuxSite. Тут — лише дані й тема магазину; код рушія — у репо `luxsite-agency/symfony-ecommerce`.

- Формат паку й перевірка: `docs/store-pack.md` рушія; перед комітом — `bin/store validate <ця тека>` з репо рушія.
- Клієнтського PHP-коду в паку v1 нема (`src/Store/` не використовується). Потрібна функція → PR у рушій з тестами.
- Тема: лише ключі з `SiteTheme::DEFAULTS` рушія (невідомий ключ ламає валідацію й сайт). Файли — `themes/storetemplate/`.
- Хости не задавати в `config/parameters.yaml` — їх кладе деплой із реєстру. Секрети — ніколи (ні тут, ні в історії git).
- Каталог і тексти в паку — початкові дані. Після першого імпорту правда — БД магазину; правки йдуть в адмінці, не в CSV.
- Факти в текстах — лише з `docs/brief.md` / `studio/persona.yaml` (verified_facts). Тексти: Gemini → редактура → чистка від ознак AI.
- Деплой, бекап, архів — `bin/store` рушія, з відома власника. Прод з dev-сервер не чіпати.
